## 1. 数据集概述

| 项 | 数值 |
|---|---|
| 图像总数 | **3053** 张 |
| 目标框总数 | **3648** 个（fire 2215 / smoke 1433） |
| 无目标（负样本）图像 | 1296 张 |
| 视频素材 | **1032 段 / 158.8 分钟** |
| 场景（拍摄单元）数 | 25 个 |
| 划分 | train 2479 / val 371 / test 203 |

**类别定义**

| id | 名称 | 含义 |
|---|---|---|
| 0 | `fire` | 明火、火焰（含蜡烛、灶火、篝火、建筑火灾、爆燃等） |
| 1 | `smoke` | 烟雾、浓烟、烟柱 |

评测一律以这两类为准；未设置细粒度子类（题目允许扩展，但评测按 fire/smoke 计）。

## 3. 目录组织规范

```
datasets/fire/
├── raw/
│   ├── images/<场景名>/*.jpg    原始图像（唯一的人工投放位置）
│   ├── videos/<场景名>/*.mp4    原始视频
│   └── clips/<场景名>/*.mp4     切分后的短片段
├── ann/
│   ├── labels/<场景名>/*.txt    YOLO 标签（人工修改的是这一份）
│   ├── raw/<场景名>/*.json      自动标注原始输出（含模型/提示词/阈值，可追溯）
│   └── masks/                   分割掩码（预留）
├── images/{train,val,test}/     划分后的图像（脚本生成）
├── labels/{train,val,test}/     划分后的标签（脚本生成）
└── meta/                        classes.txt / split.json / 统计表 / 体检报告
```

**命名约定（脚本依赖，不可随意更改）**

| 约定 | 作用 |
|---|---|
| 一个场景目录 = 一次拍摄（同一房间/机位/时段） | 划分时**整场景分配**，杜绝同源泄漏 |
| 目录名含 `neg` | 标记为无火负样本场景 |
| 目录名以 `pub_` 开头 | 标记为公开数据来源，用于统计"自行采集占比" |

## 4. 标注规范

- 格式：**YOLO txt**，每行 `类别id 中心x 中心y 宽 高`，全部归一化到 0~1
- 一张图一个同名 txt；**空 txt 表示该图无目标（负样本）**，不是漏标
- 框的规则：
  - 只框**火焰本体**与**可见烟体**，不框反光、灯光、红色物体
  - 火焰与烟雾重叠时，允许各自成框
  - 满屏火焰时，框覆盖火焰可见区域即可
- 类别顺序：**0 = fire，1 = smoke**（与公开数据集原始顺序相反，已统一转换）

**标注流程（半自动）**

1. GroundingDINO 零样本预标注（提示词 `fire, flame, burning, blaze / smoke, smoke plume, heavy smoke`）
2. 人工复核修正（X-AnyLabeling）
3. 检查脚本体检（格式、越界、跨集重复、场景泄漏）

可追溯性记录见 `ann/raw/<场景>/*.json` 与 `ann/last_run.json`（含模型名、版本、提示词、阈值、时间）。

## 5. 数据划分

- 比例：train 81% / val 12% / test 7%（测试集固定为 3 个独立场景，203 张）
- **按场景整体划分**，同一段视频抽出的帧不会跨集
- 测试集场景：`pub_firedetect_0`、`pub_firedetect_1`、`scene01_室外白天`
- 划分记录与随机种子：`meta/split.json`（seed=42）

完整统计见 `meta/dataset_stats.md`，体检结果见 `meta/label_check.md`。

## 6. 已知局限与风险（写报告时须体现）

| 问题 | 现状 | 影响 |
|---|---|---|
| **自行采集占比** | 21.1%（643/3053），低于题目 ≥30% | 需补充自拍素材才能达标 |
| 自采图像构成 | 多为火灾档案照与网络图，**非手机实拍** | 严格意义上不属"自行采集" |
| 蓝色火焰 | 外部验证集召回 23%（13 张中认对 3 张） | 对非典型火焰形态泛化不足 |
| 监控空场景视频 | 100 段无火素材，仅作负样本 | 不能充当"火灾场景视频" |
| 公开集标注质量 | 部分框较粗（含大面积背景），已清理零面积框 | 影响框回归精度 |
| 类别不平衡 | fire 2215 / smoke 1433 | 烟雾召回通常高于火焰 |

## 7. 复现方式

```powershell
python scripts/make_dirs.py                 # 建目录
python scripts/cut_videos.py --clip-len 4   # 视频切片段
python scripts/extract_frames.py --fps 0.5  # 抽帧
python scripts/autolabel.py                 # 大模型预标注
# 人工复核 ann/labels/
python scripts/split_dataset.py --ratio 0.80 0.13 0.07 \
    --train-scenes "scene03_室内逆光,scene04_后厨明火,pub_blueflame,pub_videos,pub_firestock" \
    --test-scenes "pub_firedetect_0,pub_firedetect_1,scene01_室外白天"
python scripts/check_labels.py              # 体检
python scripts/dataset_stats.py             # 统计表
```

环境：Python 3.13 / torch 2.11.0+cu128 / ultralytics 8.4.182 / RTX 5060 Laptop 8GB
