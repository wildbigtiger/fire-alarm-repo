# 模型性能对比（子任务 3 vs 子任务 4）

同一测试集：**205 张 / 346 个真值框**；同一 IoU 阈值 0.5；同一硬件（RTX 5060 Laptop 8GB）

| 指标 | YOLO11n（自训练） | GroundingDINO-tiny（零样本） | 差异 |
|---|---|---|---|
| mAP@0.5 | 0.6789 | 0.2991 | -0.3798 |
| mAP@0.5:0.95 | 0.3414 | 0.1921 | -0.1493 |
| Precision | 0.6351 | 0.2401 | -0.3949 |
| Recall | 0.6865 | 0.4393 | -0.2472 |
| F1 | 0.6598 | 0.3105 | -0.3493 |
| 端到端 FPS | 116.8 | 3.1 | -113.7 |
| 单帧耗时(ms) | 8.6 | 321.2 | 312.7 |

## 结论

- **精度**：自训练 YOLO 的 mAP@0.5 是零样本模型的 2.3 倍。
- **速度**：YOLO 端到端 FPS 是零样本模型的 38 倍，满足实时（>30FPS）要求；DINO 仅 3.1 FPS，达不到实时。
- **零样本的优势**：无需标注即可识别「火/烟」，换场景与新增类别（如 blue flame）改提示词即可，适合冷启动与长尾场景。
- **自训练的优势**：在已知场景上精度与速度全面占优，可部署到边缘设备；代价是需要标注数据且泛化依赖训练分布。
- 两者不是替代关系：推荐「零样本做冷启动预标注 + 自训练做线上主力」。
